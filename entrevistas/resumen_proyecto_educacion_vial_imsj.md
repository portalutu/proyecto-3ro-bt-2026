# Resumen para autoridades - Proyecto Educación Vial IMSJ

## Presentación general

El proyecto propone desarrollar una aplicación web para la Intendencia Municipal de San José, orientada a mejorar la comunicación pública de la sección Tránsito y facilitar la gestión de trámites vinculados a la libreta de conducir.

La propuesta busca centralizar en un único sistema la cartelera de anuncios, la agenda para prueba de manejo, la agenda para renovación de libreta de conducir, los materiales de estudio y la sección de preguntas frecuentes.

## Objetivo principal

Crear una plataforma simple y accesible que permita al público general consultar información oficial y agendar trámites, y que al mismo tiempo brinde al personal de la IMSJ una herramienta para administrar contenidos, horarios disponibles y reservas.

## Usuarios previstos

El sistema contempla dos tipos de usuarios:

* Público general
* Personal de la IMSJ

El público general utilizará una interfaz simple, con una cartelera de noticias como elemento principal y una barra superior para acceder a las funcionalidades.

El personal de la IMSJ utilizará un panel administrativo con un dashboard de agenda, gestión de noticias, carga de franjas horarias, materiales de estudio y preguntas frecuentes.

## Funcionalidades para el público general

* Consultar anuncios y noticias de la sección Tránsito.
* Agendarse para la prueba de manejo.
* Agendar renovación de libreta de conducir en modalidad normal.
* Agendar renovación de libreta de conducir en modalidad urgente con costo especial.
* Acceder a materiales de estudio para aspirantes.
* Consultar preguntas frecuentes.

## Funcionalidades para la IMSJ

* Publicar y administrar noticias visibles para el público.
* Definir período de vigencia de cada noticia.
* Cargar imagen de portada, galería de imágenes, texto y enlaces útiles.
* Gestionar el estado de una noticia como publicada o no-publicada.
* Cargar franjas disponibles para trámites normales, urgentes y prueba de manejo.
* Visualizar la agenda por día, semana o mes.
* Administrar materiales de estudio.
* Mantener la sección de preguntas frecuentes.

## Aspectos a validar con las autoridades

Durante la entrevista será importante aclarar:

* Cómo se gestionan actualmente las agendas.
* Qué datos debe ingresar el ciudadano para reservar.
* Qué diferencia operativa existe entre trámite normal y urgente.
* Si el sistema debe gestionar pagos o solamente informar costos.
* Qué funcionarios podrán publicar noticias y administrar agenda.
* Qué información debe quedar disponible públicamente.
* Qué datos personales se deben registrar y cómo deben protegerse.
* Si la propuesta será un prototipo educativo o si podría proyectarse como sistema real.

## Valor esperado

El sistema permitiría mejorar el acceso ciudadano a información oficial, ordenar la agenda de trámites y facilitar la administración interna de contenidos vinculados a educación vial.

Para el proyecto educativo, representa un caso realista de desarrollo web con gestión de usuarios, agenda, contenidos, archivos, datos personales y panel administrativo.

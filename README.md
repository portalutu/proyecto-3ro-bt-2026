## Uso del repositorio

Este repositorio funciona como espacio de coordinacion y documentacion general. Desde aqui se puede:

- Consultar las propuestas de proyecto disponibles.
- Revisar lineamientos generales y requerimientos por asignatura.
- Preparar entrevistas con autoridades o referentes institucionales.
- Revisar documentacion de apoyo para planificacion y seguimiento.
- Registrar la conformacion de grupos.
- Mantener trazabilidad entre documentos vigentes y obsoletos.

## Flujo sugerido de trabajo

1. Revisar la propuesta del proyecto asignado en `Proyectos/`.
2. Consultar los lineamientos generales en `Lineamientos/`.
3. Usar la guia correspondiente en `entrevistas/` para relevar dudas con referentes institucionales.
4. Completar la documentacion del proyecto usando las plantillas de `docs_docentes/`.
5. Registrar avances, decisiones y trazabilidad mediante Git.
